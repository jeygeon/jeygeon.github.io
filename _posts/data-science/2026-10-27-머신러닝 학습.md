# 머신러닝(Machine Learning)

머신러닝은 컴퓨터가 데이터를 학습하여 유의미한 결론을 도출하게 하는 AI의 한 유형이다.

예를들어 대량의 일반메일과 스팸메일 데이터를 학습시켜 다음에 들어오는 메일이 스팸메일인지 판단 하게 하는 역활이나, 다양한 사진을 학습시켜서 다음 사진이 그동안 학습했던 사진들의 어떤 종류인지 판단하게 하는 역활 또한 가능하다.

# 지도학습과 비지도학습

머신러닝이 데이터를 학습한다고 했는데 데이터 학습에는 **지도학습**, **비지도학습** 이렇게 두가지 알고리즘이 있다. 지도학습과 비지도학습의 가장 큰 차이는 학습시키는 데이터가 정답을 가지고 있는지 없는지의 차이이다.

## 1. 지도학습(Supervised Learning)

지도학습은 입력 데이터(Input Data)와 정답(Label)을 함께 제공하여 모델이 데이터와 정답 사이의 관계를 학습하도록 하는 머신러닝 학습 방식이다.

모델은 학습 데이터를 바탕으로 패턴을 학습하고, 학습 과정에서 보지 못한 새로운 데이터가 주어졌을 때 정답을 예측할 수 있게 된다.

지도학습은 예측하려는 정답(Label)의 유형에 따라 크게 **분류**와 **회귀**로 나뉜다.

### 1-1. 분류(Classification)

분류는 입력 데이터가 미리 정해진 범주(Class) 중 어디에 속하는지 예측하는 방법이다.
정답 라벨이 범주형 데이터일 때 사용한다.

예시

- 이메일이 스팸인지 정상 메일인지 예측
- 사진에 있는 동물이 고양이인지 개인지 예측
- 고객이 상품을 구매할지 구매하지 않을지 예측
- 거래 내역이 정상 거래인지 이상 거래인지 예측

### 1-2. 회귀(Gegression)

회귀는 입력 데이터를 바탕으로 연속적인 수치 값을 예측하는 방법이다.
정답 라벨이 수치형 데이터일 때 사용한다.

예시

- 아파트의 면적, 위치 등을 바탕으로 집값 예측
- 과거 매출 데이터를 바탕으로 다음 달 매출 예측
- 기온, 습도 등의 데이터를 바탕으로 전력 사용량 예측
- 주행 거리와 차량 상태를 바탕으로 중고차 가격 예측

## 2. 비지도학습(Unsupervised Learning)

비지도학습은 정답 라벨(Label)이 없는 데이터를 모델에 제공하고, 데이터 자체에 존재하는 패턴이나 구조, 특징을 학습하도록 하는 머신러닝 학습 방식이다.

지도학습은 입력 데이터와 정답을 함께 사용하지만, 비지도학습은 정답 없이 데이터 간의 유사성이나 차이점 등을 분석하여 의미 있는 정보를 찾아낸다.

비지도학습은 목적과 분석 방법에 따라 군집화, 차원 축소, 연관 규칙 학습 등으로 구분할 수 있다.

### 2-1. 군집화(Clustering)

군집화는 데이터 간의 유사성을 바탕으로 비슷한 데이터끼리 그룹으로 묶는 방법이다.
미리 정답 그룹을 지정하지 않고 데이터의 특징을 분석하여 군집을 형성한다.

예시

- 고객의 구매 패턴을 분석하여 고객 그룹 구분
- 뉴스 기사를 주제별로 자동 분류
- 유사한 특성을 가진 상품들을 그룹화
- 센서 데이터에서 비슷한 행동 패턴 탐색

### 2-2. 차원축소(Dimension Reduction)

차원 축소는 데이터가 가진 여러 특성을 더 적은 수의 특성으로 압축하면서 중요한 정보를 최대한 보존하는 방법이다.

예를 들어, 고객 데이터에 나이, 소득, 구매 금액, 방문 횟수 등 수십 개의 특성이 있다면 이를 더 적은 차원으로 표현하여 데이터의 구조를 파악할 수 있다.

예시

- 수백 개의 특성을 가진 데이터를 2차원 그래프로 시각화
- 고차원 데이터의 복잡성 감소
- 데이터의 중복되거나 상관성이 높은 정보 압축
- 머신러닝 모델의 학습 및 데이터 분석 지원

### 2-3. 연관성 규칙 발견(Association Rule)

연관 규칙 학습은 데이터에서 항목들 사이에 자주 함께 나타나는 관계나 패턴을 발견하는 방법이다.

예를 들어, 고객의 장바구니 데이터를 분석했을 때 빵을 구매한 고객이 우유도 자주 구매하는 패턴을 발견할 수 있다.

예시

- 마트에서 함께 구매되는 상품 분석
- 온라인 쇼핑몰의 상품 추천
- 고객의 구매 행동 패턴 분석
- 서비스 이용 항목 간의 연관성 탐색
