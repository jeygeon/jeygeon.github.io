1. 데이터 가져오기 위한 라이브러리 임포트

```python
import pandas as pd
```

2. "data.csv" 파일을 읽어와 df이라는 변수에 저장

```python
pd.read_확장자("파일명")

df = pd.read_csv("data.csv")
df2 = pd.read_excel("data2.xlsx")
```

3. 저장한 df에서 인덱스를 제외하고 clean_data.csv라는 파일명으로 다시 저장

```python
df.to_csv("clean_data.csv")
```

4. "data.xlsx"을 json 파일로 저장

```python
# data.xlsx 파일을 읽어서 df_excel 변수에 저장
df_excel = pd.read_excel("data.xlsx")

# 저장한 df_excel을 json파일로 변환해서 저장
# orient="records" 옵션을 추가할 경우 excel의 각 행별로 각 json객체를 생성하여 저장됨
df_excel.to_json("df_json.json", orient="records")
```
