AICE 시험의 첫 단계는 데이터 분석 및 머신러닝에 필요한 라이브러리와 모듈을 올바르게 불러오는 능력을 평가한다.

`import` : 전체 라이브러리를 불러온다. <br/>
`import 라이브러리 as 별칭` : 라이브러리를 특정 별칭으로 불러온다. <br/>
ex) `import pandas as pd` <br/>
`from 모듈 import 함수` : 모듈 내 특정 함수만 불러온다. <br/>

1. 라이브러리 import

```python
import pandas as pd
import numpy as np
```

2. 특정 라이브러리의 모듈에서 함수 import

```python
from sklearn.model_selection import train_test_split
```

3. 여러 라이브러리를 한줄에 import 하는 것도 가능하다

```python
import pandas as pd, numpy as np, matplotlib.pyplot as plt, seaborn as sns
```
