## 기초 문법 정리

### 기초 문법

원하는 값 출력

```python
print("hello world")

# 실행결과
hello world
```

### 변수

파이썬은 자바와 달리 변수의 자료형을 따로 표시하지 않아도 된다. 파이썬이 저장된 값을 보고 자료형을 자동으로 판단한다.

```python
name = "철수"     # 문자열
age = 20         # 정수
height = 175.5   # 실수
```

자료형은 `type()`으로 판별 가능하다.

```python
age = 20
height = 175.5
name = "철수"
student = True

print(type(age))
print(type(height))
print(type(name))
print(type(student))

# 실행결과
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

### 숫자연산

```python
a = 10
b = 3

print(a + b)   # 더하기
print(a - b)   # 빼기
print(a * b)   # 곱하기
print(a / b)   # 나누기
print(a // b)  # 몫
print(a % b)   # 나머지
print(a ** b)   # 제곱

# 실행결과
13
7
30
3.3333333333333335
3
1
1000
```

### 문자열

```python
name = "Python"

print(name)

# 문자열 관련 함수
len(name) # 6
text(name[0]) # P
text(name[1]) # y
text(name[2]) # t
```

### 사용자 입력받기

`input()`을 사용하면 사용자의 값을 입력받을 수 있다.

```python
name = input("이름을 입력하세요: ")

print("안녕하세요, {name}님!")

# 실행결과
이름을 입력하세요: 철수
안녕하세요, 철수님!
```

참고로 `input()`으로 입력받은 값은 문자열이기 때문에 형 변환이 필요하다

```python
age = int(input("나이를 입력하세요: ")) # int()로 정수로 형변환

print(age)
```
