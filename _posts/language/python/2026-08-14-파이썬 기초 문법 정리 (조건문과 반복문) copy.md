## if 조건문

```python
age = 20

if age >= 20:
    print("성인입니다.")


if age >= 20:
    print("성인입니다.")
else:
    print("미성년자입니다.")

score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("F")
```

## 논리연산자

```python
age = 25
money = 10000

# and : 두 조건 모두 참일 경우
if age >= 20 and money >= 50000:
    print("입장가능합니다.")

# or : 두 조건 중 하나라도 참일 경우
day = "토요일"
if day == "토요일" or day == "일요일":
    print("주말")

# not : 조건의 결과를 반대로 만든다
is_raining = False

if not is_raining:
    print("우산이 필요없다.")
```

## for 반복문

```python
for i in range(5):
    print(i)

# 실행결과
0
1
2
3
4
```

```python
peoples = ["Lee", "Kim", "Park"]
for p in peoples:
    print(p)

# 실행결과
Lee
Kim
Park
```

ex) 구구단 만들어보기

```python
for i in range(1, 10):
    print(f"2 x {i} = {2 * i}")

# 실행결과
2 x 1 = 2
2 x 2 = 4
2 x 3 = 6
...
2 x 9 = 18
```

## while 반복문

```python
i = 1
while i <= 5:
    print(i)
    i += 1

# 실행결과
1
2
3
4
5
```

### 반복문 제어 : break / contiue

```python
for i in range(1, 11):
    if (i == 5):
        break

    print(i)

# 실행결과
1
2
3
4
```

```python
for i in range(1, 11):
    if (i == 5):
        contiue

    print(i)

# 실행결과
1
2
3
4
6
7
8
9
10
```
