## 상속

기존 클래스의 기능을 물려받는 것. 상속을 하게 되면 부모와 자식 클래스가 존재하게 된다.

```python
class Member:

    def __init__(self, name, age):
        self.name = name
        self.age = age
```

```python
class Student(Member):

    def __init__(self, name, age, job):
        super().__init__(name, age, job)
        self.job = job

    def introduce:
        print("학생입니다.")
```

```python
class Teacher(Member):

    def __init__(self, name, age, job):
    super().__init__(name, age, job)
    self.job = job
```
