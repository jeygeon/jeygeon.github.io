## 함수

### 구조

```python
def 함수명():
    실행할 코드
```

### 선언

```python
# 선언
def hello():
    print("hello world")

# 호출
hello()

# 결과
hello world
```

### 매개변수

```python
# 선언
def hello(name):
    print(f"안녕하세요, {name}님!")

# 실행
hello("철수")

# 결과
안녕하세요, 철수님!
```

### return

`return`을 통해서 결과 값을 반환할 수도 있다. 함수가 실행되면서 `return`을 만나게 되면 함수는 바로 종료되고, 값은 바로 return된다.

```python
# 선언
def add(a, b):
    return a + b

# 실행
result = add(3, 5)
```

### 기본값 매개변수

함수의 인자로 아무 값도 전달되지 않았을 때 기본 값 설정도 가능하다

```python
# 선언
def hello(name="손님"):
    print(f"안녕하세요, {name}님!")

# 실행
hello() # 안녕하세요, 손님님!
hello("철수") # 안녕하세요, 철수님!
```

### 여러 값 return 받기

하나의 값이 아닌 여러 값도 `return`받을 수 있다.

```python
# 선언
def calculate(a, b):
    return a + b, a - b

# 실행
plus, minus = calculate(5, 1)

# 결과
print(plus) # 6
print(minus) # 4
```
