## 리스트

```python
peoples = ["Lee", "Kim", "Park"]
print(peoples)

# 결과
['Lee', 'Kim', 'Park']
```

```python
peoples = ["Lee", "Kim", "Park"]
for p in peoples:
    print(p)

# 결과
Lee
Kim
Park
```

### 데이터 추가

```python
peoples = ["Lee", "Kim", "Park"]
peoples.appen("Jung")

print(peoles)

# 결과
['Lee', 'Kim', 'Park', 'Jung']
```

### 데이터 삭제

```python
peoples = ["Lee", "Kim", "Park"]
peoples.remove("Lee")

print(peoples)

# 결과
['Kim', 'Park']
```

### 리스트에서 숫자 다루기

```python
numbers = [10, 20, 30, 40, 50]

print(len(numbers))
print(max(numbers))
print(min(numbers))
print(sum(numbers))

# 결과
5
50
10
150
```

## 딕셔너리

딕셔너리는 키(key)와 값(value)의 형태로 존재

```python
person = {
    "name": "철수",
    "age": 25,
    "gender": "M"
}

# 값 출력
print(person["name"]) # 철수
print(person["age"]) # 25
print(person["gender"]) # M
```

```python
person = {
    "name": "철수",
    "age": 25,
    "gender": "M"
}

# 값 추가
person["job"] = "student"
```

```python
person = {
    "name": "철수",
    "age": 25,
    "gender": "M"
}

# 값 출력
for key, value in person.items():
    print(key, value)

# 결과
name 철수
age 25
gender M
```
