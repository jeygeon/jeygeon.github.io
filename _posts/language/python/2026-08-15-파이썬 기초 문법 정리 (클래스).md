## 클래스(Class)

### 정의

```python
class 클래스명:
    메소드 정의
```

### ex) Member 객체 생성

```python
class Member:

    def __init__(self, name, age, gender):
        self.name = name
        self.age = age
        self.gender = gender

    def introduce(self):
        print(f"이름 : {self.name}, 나이 : {self.age}, 성별 : {self.gender}")
```

1. `__init__` : 객체가 만들어질 때 자동으로 실행되는 초기화 함수 <br/>
   ex)
   ```python
   member = Member("홍길동", 25, "M")
   ```
   위의 코드로 member객체를 생성할 수 있는데 `__init__` 함수가 자동으로 호출되면서 객체가 생성이 됨
2. `self` <br/>
   `self`는 객체 자기 자신을 가리킨다. 객체를 정의하고 함수를 만들 때 첫번째 매개변수로 꼭 들어가야 한다.
